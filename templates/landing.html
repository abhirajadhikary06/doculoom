16 intelligence capabilities

More than a chatbot. A knowledge system.

⏱

Temporal Reasoning

Understands document timelines. Answers "what was the rule in 2024?" differently from "what is the rule today?" and shows you the full supersession chain.

Feature A
✅

Evidence Verification

Every claim in an answer is matched against a source passage and classified as supported, unsupported, or insufficient. Citation coverage is always shown.

Feature B
🧭

Adaptive Retrieval

Picks the right retrieval strategy for each question — keyword search for facts, semantic search for explanations, temporal search for historical queries.

Feature C
⚡

Impact Analysis

After every upload, automatically detects which existing documents are affected, extracts cross-document relationships, and flags potential conflicts.

Feature D
🔍

Provenance Explorer

Every answer is fully traceable. See the exact passages retrieved, their scores, which claim each one supports, and replay any historical query.

Features E + I
💾

Semantic Cache

Reuses semantically similar answers only when the document versions and tenant context match. Prevents stale answers after document updates.

Feature F
🩺

Self-Healing Ingestion

Measures text coverage, OCR confidence, and chunk quality on every upload. Quarantines low-quality documents and supports targeted reprocessing.

Feature G
⚗️

Counterfactual Testing

Test whether document changes produce the expected answer changes — without touching production data. Detects retrieval regressions before they reach users.

Feature H
🔀

Query Decomposition

Complex multi-part questions are split into independent sub-queries, each retrieved separately, then synthesised into one consistent cited answer.

Feature J
⚠️

Contradiction Discovery

Proactively scans all documents and surfaces conflicting percentages, amounts, and policy statements — with severity levels and a one-click resolve action.

Feature K
🕐

Knowledge Expiration

Tracks expiry dates, effective periods, and supersession status. Flags documents for admin review before they silently give students outdated answers.

Feature L
📡

Drift Detection

Runs Recall@K, MRR, and nDCG against a labeled baseline after every index change. Fires an alert when retrieval quality drops beyond a configurable threshold.

Feature M
🏅

Document Trust Scoring

Each document gets a transparent trust score from 8 individual factors — source authority, recency, validity, extraction quality — not an opaque AI number.

Feature N
📊

Difficulty Estimation

Classifies every question before retrieval. Simple factual lookups skip the expensive reranker. Multi-document questions automatically trigger decomposition.

Feature O
🗺

Knowledge Gap Discovery

Tracks every unanswered question, clusters them semantically, and generates admin-facing reports telling you exactly which documents to upload next.
